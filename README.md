# Photography Portfolio Website

A responsive photography portfolio website built using HTML, CSS, and Bootstrap. This project was created to practice frontend development by recreating a modern portfolio layout with responsive design principles.

## Features
- Responsive navigation
- Hero section
- Services section
- About section
- Testimonials
- Blog section
- Contact form
- Bootstrap cards and grid system
- Smooth scrolling

## Technologies Used
- HTML
- CSS
- Bootstrap 5

## Purpose
To strengthen frontend development skills by building a responsive portfolio website inspired by a real-world design.
